服务器回复 ServerHello，并把数字证书发给浏览器。证书里包含：
域名
服务器公钥
有效期
CA 的数字签名
浏览器用本地内置的受信任 CA 公钥验证证书签名，检查证书是否过期、域名是否匹配、是否被吊销。
从证书中取出公钥
| 步骤 | 浏览器做什么 | 判断什么 |
|---|---|---|
| 1. 构建证书链 | 从终端证书出发，找到中间证书，再找到本地受信任根证书 | 证书链是否完整 |
| 2. 验证签名 | 用上级 CA 公钥解密当前证书的签名，得到哈希值 H2；再自己重新计算证书内容哈希 H1；比较 H1 和 H2 | 证书是否被篡改、是否由该 CA 签发 |
| 3. 检查有效期 | 查看证书的 `Not Before` 和 `Not After` | 证书是否过期或尚未生效 |
| 4. 检查域名 | 核对证书中的域名、SAN 字段是否与当前访问域名一致 | 是否访问到正确网站 |
| 5. 检查吊销状态 | 通过 CRL 或 OCSP 查询证书是否被吊销 | 证书是否已被 CA 作废 |
| 6. 检查扩展字段 | 检查 Key Usage、Basic Constraints 等 | 证书是否被允许用于 TLS 服务器认证 |
