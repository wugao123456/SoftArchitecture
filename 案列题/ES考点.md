结合近几年真题看，ES 在系统架构师案例分析里主要不是考“怎么调 API”，而是考：**倒排索引原理、分词器、分布式架构、高可用设计、性能优化、数据同步、选型对比**。

### 1. 倒排索引与检索原理

常考“ES 为什么适合全文检索”。要能说清：

- 正排索引是“文档 → 词”，倒排索引是“词 → 文档列表”；
- 查询时先分词，再查词项字典，合并文档列表，最后打分排序；
- ES 基于 Lucene，适合海量文本、模糊匹配、相关性排序场景。

### 2. 分词器与字段类型

这是近年高频点，2024 年案例题就考过 ES 分词器。

需要掌握：

| 分词器 | 特点 | 适用场景 |
|---|---|---|
| Standard | 按标点、空格等切分，支持多语言 | 通用英文、简单文本 |
| Simple | 只保留字母，非字母作为分隔符 | 纯字母单词检索 |
| Whitespace | 仅按空白字符切分 | 已预分词的文本 |
| Keyword | 不分词，整体作为一个词 | ID、状态、标签精确匹配 |
| IK | 中文分词，支持 ik_smart / ik_max_word | 中文商品搜索、文档搜索 |

同时要区分：

- **text**：会分词，适合全文检索；
- **keyword**：不分词，适合精确匹配、聚合、排序。

### 3. 分布式架构：分片、副本、节点角色

案例题常给一个集群架构图或日志平台场景，让你分析分片、副本、节点角色。

重点：

- **主分片**决定数据水平扩展能力，创建后数量不能直接修改；
- **副本分片**提升可用性和读吞吐，故障后可提升为主分片；
- 总分片数 = 主分片数 ×（副本数 + 1）；
- 节点角色通常包括：**Master 节点、Data 节点、Coordinating 节点、Ingest 节点**。

### 4. 高可用与故障恢复

常和“日志平台、搜索服务、两地三中心”场景结合。

要能答：

- 副本分片如何避免单点故障；
- 主节点选举如何避免脑裂；
- 节点故障后副本如何提升为主分片；
- 多可用区/多机房部署如何提升容灾能力；
- 跨集群复制可用于灾备或读写分离。

### 5. 写入流程与近实时搜索

案例题可能问“为什么写入后不能立刻查到”或“写入性能怎么优化”。

关键概念：

- 写入先到主分片，再同步副本；
- 数据先写内存 Buffer 和 Translog；
- 默认约 1 秒 Refresh 后才可被搜索，所以是**近实时**；
- Flush 把 Segment 落盘并清理 Translog；
- 优化写入可用 Bulk 批量写入、调整 refresh_interval、合理设置分片数。

### 6. 查询优化与聚合分析

常考“查询变慢怎么办”。

要能答：

- 精确匹配用 `term`，全文检索用 `match`；
- `filter` 不参与打分，可缓存，适合状态、时间范围、类目过滤；
- 避免 `wildcard`、`regexp` 前缀通配；
- 深分页避免用大 `from + size`，改用 `search_after` 或滚动查询；
- 聚合分析适合做日志统计、监控指标、商品维度分析。

### 7. 索引设计与生命周期管理

日志、监控、审计类场景很常见。

重点：

- 按时间滚动索引，比如按天/按小时创建索引；
- 单分片不宜过大，常见建议控制在几十 GB 量级；
- 使用 ILM 做热/温/冷分层；
- 过期索引自动删除或归档；
- 历史索引可做 force merge 降低碎片。

### 8. 数据同步与一致性

案例题可能问“MySQL 数据如何同步到 ES”。

常见方案：

- 应用双写；
- 基于 Binlog 的增量同步，如 Canal + Logstash；
- 消息队列异步同步；
- 定时批量重建索引。

要能说明权衡：双写简单但一致性风险高；Binlog 同步解耦更好，但链路更长；ES 通常适合最终一致性场景。

### 9. 技术选型对比

可能让你比较 MySQL、Redis、HBase、MongoDB、ES 的适用场景。

可以这样记：

- MySQL：事务、强一致、复杂关联查询；
- Redis：热点缓存、低延迟 KV；
- HBase：海量列式存储；
- MongoDB：文档型、灵活 Schema；
- ES：全文检索、日志分析、聚合统计、模糊搜索。

### 10. 典型案例题型

最常出现的是：

- 电商/内容搜索平台：索引设计、分词器、相关性排序；
- ELK 日志平台：写入瓶颈、分片规划、冷热分层；
- 集群性能下降：分片过大、历史索引未清理、慢查询；
- 前后端分离架构中 ES 作为搜索服务层；
- 分布式系统高可用：副本、故障切换、跨机房部署。

备考时建议重点练三块：**分词器对比、分片副本计算、日志平台性能优化方案**。这三类最容易在案例题里直接拿分。
