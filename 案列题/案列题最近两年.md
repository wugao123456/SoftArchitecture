### 2024-2026年软考系统架构设计师案例分析题考点总结

软考架构师案例分析题固定为5道主观大题，第1题必做，后4题选做2题，满分75分，核心考察架构实战分析与方案设计能力。最近两年（2024年两次、2025年下半年、2026年上半年）考点梳理如下：

#### 一、各次考试具体考点拆解
**2024年上半年**
- **必做题**：软件质量属性效用树构建、质量属性场景六要素拆解、架构评估（风险点/敏感点/权衡点识别）
- **选做题**
1. 微服务架构与单体架构对比、UML交互图分析
2. Redis命令应用、分布式锁实现（结合ZSet等数据结构）
3. MongoDB地理信息存储、大数据Lambda架构设计
4. 嵌入式系统架构分析

**2024年下半年**
- **必做题**：软件质量属性场景判断、架构评估方法应用
- **选做题**
1. Web应用架构设计（传统架构分析）
2. 数据库缓存优化（Redis相关策略）
3. 嵌入式系统架构设计
4. 分布式事务处理方案

**2025年上半年**
**必做题**：本题以在线大模型训练平台为背景，主要考查两个核心知识点：
- **质量属性场景识别（12分）**：给出12个具体需求场景，要求填写对应的质量属性名称。例如“用户提交任务后1分钟内完成资源分配”对应性能，“数据库故障时20分钟内切换备用库”对应可用性，“功能扩展3天内完成”对应可修改性等。
- **解释器风格架构（13分）**：要求补全解释器风格架构的组成图（用户代码→解析器→执行引擎→资源调度器→硬件平台），并分析该平台为何适合采用解释器风格，答案要点包括动态执行、硬件抽象、即时优化、扩展性、跨平台兼容性等。

- **选做题**
- 补全知识图谱分层架构图（数据层、知识层、业务层及其内部模块，如数据清洗、知识获取、知识管理等）（9分）
- 补全Scrapy爬虫架构图，并简述异步I/O的特点和优势
- 说明知识图谱的构建流程和智能问答的存储实现方式（如图数据库Neo4j存储、向量检索等）

选做二：Redis缓存机制
- 补全Redis主从复制中全量同步的流程图（涉及BGSAVE命令、状态同步等细节）（10分）
- 补全增量复制的流程图（6分）
- 列举Redis两种持久化方法（RDB和AOF）并比较各自的优缺点（9分）

- 解释云端AI和端侧AI的定义，说明端侧AI相比云端AI的优势（低延迟、隐私保护、成本优化等）（6分）
- 将给定选项填入对应描述的场景中（7分）
- 对比集中式资源池、分布式资源池、混合云资源池，写出集中式资源池的三个弊端（12分）

- 考查区块链的六层架构、智能合约概念及应用场景

**2025年下半年**
- **必做题**：软件质量属性场景六要素拆解、质量属性判断（可修改性/可用性/易用性/可测试性/安全性区分）、AES-256加密长数据处理方案
- **选做题**
1. 领域驱动设计（DDD）限界上下文划分、跨平台数据同步方案
2. Redis缓存击穿解决方案（互斥锁vs逻辑过期方案对比）
3. 嵌入式智能化操作系统（AI for OS/OS for AI区分、轻量化内核特点）
4. Petri网业务流程建模、关联矩阵构建

**2026年上半年**
- **必做题**：软件质量属性判断、架构风格识别（含知识图谱相关内容）
- **选做题**
1. Redis缓存策略、悲观锁/乐观锁应用
2. 物联网（IoT）分层架构设计、边缘计算应用
3. 智能家居系统架构、QoS服务质量分析
4. 知识图谱构建与应用

#### 二、高频核心考点
1. **软件质量属性（每年必考）**：质量属性场景六要素（刺激源、刺激、环境、制品、响应、响应度量）拆解、不同质量属性（性能、可用性、安全性、可修改性、易用性、可测试性）的场景判断、架构评估方法（ATAM/SAAM）相关概念
2. **分布式缓存技术**：Redis相关考点高频出现，包括缓存击穿/穿透/雪崩解决方案、分布式锁实现、常用数据结构（ZSet等）的应用场景
3. **新技术融合应用**：AI与系统融合（AI for OS/OS for AI）、云原生架构、物联网分层架构、领域驱动设计（DDD）、知识图谱等近年新增考点占比提升
4. **架构设计与建模**：微服务架构对比单体架构、UML建模、Petri网流程建模、架构选型权衡分析

#### 三、命题趋势与备考建议
**命题趋势**
- 必做题稳定考质量属性相关，是送分题必须拿下
- 选做题区分度加大，传统考点（Redis、架构建模）难度适中，新技术考点（AI融合、物联网、知识图谱）需要额外积累
- 越来越侧重实践应用，不是纯理论，要结合具体场景分析方案优缺点

**备考建议**
1. 先把质量属性六要素、常见质量属性场景判断练熟，必做题稳拿20+分
2. 重点吃透Redis缓存相关问题、微服务架构、DDD限界上下文这几个高频选做考点
3. 适当了解AI与系统融合、物联网分层架构、知识图谱等新技术的基础概念，遇到选做不会的题可以结合题干信息分析得分

### 一、 必答题：架构评估与质量属性（几乎年年必考）
这部分是送分题也是基础题，必须拿满。
*   **质量属性场景识别**：给出具体业务场景（如“故障切换时间<30秒”、“新增API接口需3天完成”），让你判断属于哪种质量属性（可用性、可修改性、性能等）。
*   **ATAM评估方法**：考查质量属性效用树，以及敏感点、权衡点、风险点、非风险点的定义与识别。
*   **架构风格**：解释器风格、管道-过滤器、黑板风格等经典架构的组成图填空和适用性分析。

### 二、 选答题：高频核心考点（四选二）

#### 1. 微服务与分布式架构（超高频）
*   **服务拆分与治理**：基于DDD的限界上下文划分、服务粒度问题、服务注册发现（Nacos/Eureka）、API网关、Service Mesh。
*   **分布式事务**：2PC、TCC、SAGA、可靠消息最终一致性等方案的选型与对比。
*   **高可用设计**：集群部署、熔断降级（Sentinel）、限流策略、多活容灾。

#### 2. 数据架构与缓存（超高频）
*   **Redis深度应用**：这是近几年的“钉子户”考点，且越来越细。包括缓存穿透/击穿/雪崩的解决方案、主从同步流程（全量/增量）、持久化（RDB/AOF）对比、分布式锁实现。
*   **大数据架构**：Lambda架构（批处理层/速度层/服务层）、Kappa架构、多源异构数据集成、ETL流程。
*   **NoSQL数据库**：MongoDB、ElasticSearch等的应用场景与选型对比。

#### 3. 云原生架构（新兴高频）
*   **容器化与编排**：Docker、Kubernetes的HPA/VPA弹性伸缩策略、声明式API。
*   **可观测性**：这正是你论文中写过的方向——指标采集（Prometheus）、链路追踪（SkyWalking/Jaeger）、日志聚合（ELK）的体系构建。
*   **Serverless**：FaaS/BaaS的特点与应用场景。

#### 4. 嵌入式与AI架构（轮换考点）
*   **嵌入式系统**：实时性、可靠性设计，以及AI与OS的融合（AI for OS vs OS for AI）。
*   **AI工程化**：大模型训练平台架构、端-边-云混合架构、知识图谱构建。

#### 5. 传统基础（保底考点）
*   **UML建模**：类图、时序图、活动图的关系识别与填空。
*   **数据库设计**：ER图、范式理论、SQL优化、索引设计。
*   **需求工程**：需求获取方法、DFD数据流图。

### 三、 备考建议
1.  **发挥你的优势**：你在大数据处理中台项目中积累的**指标采集、规则引擎告警、智能监控平台**等经验，完美契合“可观测性”和“自动化运维”考点，这部分可以直接作为案例题的答题素材。
2.  **补齐短板**：Redis相关的考点非常细（甚至考具体命令），建议重点刷一下Redis主从同步流程和缓存异常场景的解决方案。
3.  **关注AI方向**：2025-2026年AI相关题目明显增多，即使不选做，也要了解基本概念（如端侧AI vs 云端AI、知识图谱分层架构）。

## 三点结论（按复习优先级）

1. **质量属性 + 架构风格 = 必拿板块**（6/7、4/7）。几乎每场第1题必考，套路固定：判属性 → 6要素描述场景 → 架构风格选择。这是案例题的"基本盘"。
2. **Redis/缓存类是第二高频**（5/7），但考点逐年演化：读写分离(23.5) → ZSet命令/分布式锁(24.5) → Cache-Aside(24.11) → 主从/RDB-AOF(25.5) → 悲观乐观锁/超卖(26.5)。**不能只背主从复制，要补并发锁与高并发治理**。
3. **新技术年年换新，但题型多为填空填图**：区块链(25.5)、Petri/DDD(25.11)、云边协同/时序库/MQTT/向量库(26.5)。教材里没有，靠"读题+原理迁移"应对，不必死磕细节。
